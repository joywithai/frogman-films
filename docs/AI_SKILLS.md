# AI Coding-Agent Skills & Workflow Standards

This document records the five AI engineering skills and development standards specified for building **Frogman Films**. These are development-time instructions and practices for coding agents, not runtime dependencies in Next.js.

---

### 1. Ponytail — Disciplined Engineering
- **Repository:** `https://github.com/DietrichGebert/ponytail`
- **Purpose:** Focus on small, complete changes, reuse established codebase patterns, inspect callers/tests, avoid unnecessary dependencies, and preserve validation, security, and accessibility.
- **Install:** `npx skills add DietrichGebert/ponytail`

### 2. Diagram Design — Architecture & Data Diagrams
- **Repository:** `https://github.com/cathrynlavery/diagram-design`
- **Purpose:** Standardized Mermaid diagrams for system architecture, PostgreSQL entity relationships, checkout payment flows, and digital asset lifecycle.
- **Install:** `npx skills add cathrynlavery/diagram-design`

### 3. UI/UX Pro Max — Design System & Human-Centered UX
- **Repository:** `https://github.com/nextlevelbuilder/ui-ux-pro-max-skill`
- **Purpose:** Design tokens, editorial typography, accessible touch targets (min 44px), focus states, and responsive layout patterns adhering to the `#070709` vintage book/film archive aesthetic.
- **Install:** `npx ui-ux-pro-max-cli init --ai antigravity`

### 4. Impeccable — Visual Craft & Critique
- **Repository:** `https://github.com/pbakaus/impeccable`
- **Purpose:** Visual audit of margins, restrained film grain, contrast ratios, smooth clamped eye tracking, and natural multi-stage wake-up animations.
- **Install:** `npx impeccable install`

### 5. Hallmark — Distinctive Non-Generic Design
- **Repository:** `https://github.com/Nutlope/hallmark`
- **Purpose:** Anti-generic design checklist: avoids cookie-cutter SaaS layouts, repetitive card grids, meaningless icon soups, and neon gradients.
- **Install:** `npx skills add nutlope/hallmark -g`
